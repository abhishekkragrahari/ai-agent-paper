# FINAL_CLAIM_AUDIT.md

Every substantive claim used in the project, classified. "Established fact" = verifiable from a primary or strongly-corroborated source independent of this project. "Prior-work result" = a specific finding reported by one of the six audited papers. "Theorem/proposition" = proved in this project. "Experimental result" = produced by running code in this project. "Hypothesis" = stated, testable, not yet resolved. "Interpretation" = a reasoned inference, not itself independently provable. "Limitation" = an acknowledged gap or weakness.
